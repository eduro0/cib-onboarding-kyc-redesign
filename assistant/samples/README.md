# Sample KYC packs

Every company, person, address and number here is **fictional**, made up for this demo. Any resemblance to a real
entity is accidental. Each folder is one client: `*.txt` documents as the client would upload them, plus
`bank-file.json` for a periodic review (what the bank already holds).

- `harbour-lantern`: new client onboarding. A Hong Kong trading company owned through a Singapore holding company.
- `kestrel-bay`: periodic review where the registry shows a new director and a new 30% shareholder.
- `quiet-pine`: periodic review where nothing material has changed.
