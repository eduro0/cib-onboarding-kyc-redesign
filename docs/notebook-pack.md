# Gemini Notebook pack: the public rules, ready to ask

This pack sets up a notebook over the public rules the project relies on, so anyone can check a claim against the
source. Google's notebook tool, formerly NotebookLM, is now called Gemini Notebook. It is free with a Gmail
account and takes up to 50 sources per notebook on the free plan [src:gemini-notebook-plans-limits]. Its
availability in Hong Kong was not checked; if it isn't offered there, ask the same questions in a chat with the
Gem and attach a few of the PDFs below (the Gem's file limit is unverified, so start with four: the HKMA
guideline, the 2024 CDD circular, the 2019 AI principles and MAS Notice 626). Allow about 20 minutes.

## Five questions that show it working

Each answer should cite the passage named; if it cites something else, check it before using it.

1. **Ask:** "Who counts as a beneficial owner of a Hong Kong company?" A good answer quotes AMLO Schedule 2 (more
   than 25%, directly or indirectly, or ultimate control over management) and HKMA Guideline para 4.4.9 [src:hk-amlo-sch2] [src:hkma-aml-cft-guideline-2023].
2. **Ask:** "How often must a high-risk corporate client be reviewed, and what triggers an earlier review?" A good
   answer cites Guideline para 5.3 (at least annually) and para 4.12.2 (trigger events such as a change in
   beneficial ownership) [src:hkma-aml-cft-guideline-2023].
3. **Ask:** "May a bank ask a client again for documents it already holds?" A good answer cites the 2024 circular
   (requests should not duplicate information already held or publicly available) [src:hkma-rba-cdd-2024].
4. **Ask:** "What does the HKMA expect about human oversight of AI?" A good answer cites the 2019 principles
   (accountability, explainability, human-in-the-loop controls), the 2024 circular for customer-facing use, and
   the 2026 speech on the shift to human-on-the-loop [src:hkma-ai-high-level-principles-2019]
   [src:hkma-genai-consumer-protection-2024] [src:hkma-speech-finance-ai-forum-2026].
5. **Ask:** "How does Singapore's approach to periodic review differ from Hong Kong's?" A good answer cites MAS
   Notice 626 and its Guidelines [src:mas-notice-626] [src:mas-guidelines-notice-626].
