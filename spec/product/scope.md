# Scope

- **one-process:** (decided) The project redesigns one process, corporate client onboarding plus the periodic KYC review that keeps the file current, because one process done end to end shows the method better than several done thinly.
- **wholesale-client:** (decided) The client is a corporate in wholesale banking (a trading company with a holding structure), which is the function the role asks for.
- **hong-kong-rules:** (decided) Rules are Hong Kong's (AMLO and the HKMA AML/CFT Guideline), with Singapore's MAS Notice 626 noted where it differs, because the team covers Asia branches.
- **core-coverage:** (decided) The project delivers at least: As-Is and To-Be BPMN maps with human-approval gates and moments of truth, a KPI model (cycle time, touch time, first-pass rate) in Google Sheets and Looker Studio, a roadmap and a change-risk plan.
- **tool-coverage:** (decided) The set also covers the everyday Google and AI tool set (Google Slides, Docs, Sheets, Looker Studio, Sites, a custom Gem or GPT, NotebookLM), each with the file to load and the exact steps.
- **two-three-days:** (decided) Scope fits about two to three days of work, so a first version can be shown quickly.
